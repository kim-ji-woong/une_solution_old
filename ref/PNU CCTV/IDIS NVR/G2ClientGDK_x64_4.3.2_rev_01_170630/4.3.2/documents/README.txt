1. You can see the basic operation with IDIS DVR/NVR by executing three files.

/bin/tester_watch.exe  : live monitoring operation
/bin/tester_search.exe : playback operation
/bin/tester_status.exe : checking status (such as motion detection, alarm, text input and so on.)

/tester/csharp/tester_watch  : source code for tester_watch.exe

/tester/csharp/tester_status : source code for tester_status.exe
